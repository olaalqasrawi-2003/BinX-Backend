# Day 01 - C# Backend Internship

## Overview
This is the first day's work of the BinX Backend Internship. The objective was to prepare the development environment, learn the project structure, and create the initial C# console application.

## Objectives
- Set up the development environment.
- Create the internship folder structure.
- Create the first C# Console Application.
- Understand the basic project files generated by .NET.
- Run the application successfully.

## Tasks Completed

### 1. Project Structure
Created the following directory structure:

```
BinX-Backend-Internship/
└── Week-01/
    ├── Day-01/
    └── Day-02/
```

### 2. Create a Console Application

Created a new C# Console Application using the .NET CLI.

```bash
dotnet new console -o HelloBinX
```

### 3. Project Files

Learned the purpose of the generated files:

- `Program.cs` – Application entry point.
- `.csproj` – Project configuration file.
- `bin/` – Compiled application output.
- `obj/` – Temporary build files.

### 4. Running the Application

Executed the project using:

```bash
dotnet run
```

Output:

```
Hello, World!
```
