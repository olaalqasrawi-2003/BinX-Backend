# Day 02 - C# Fundamentals

## Overview

The second day of the BinX Backend Internship focused on learning the fundamentals of C#. The tasks introduced essential programming concepts that form the foundation for backend development.

## Objectives

- Understand C# value types and reference types.
- Learn how copying works for different data types.
- Practice working with nullable reference types.
- Read user input from the console.
- Initialize and upload the project using Git and GitHub.

## Tasks Completed

### 1. Value Types vs Reference Types

Created variables using different C# data types and displayed their runtime types using the `GetType()` method.

**Value Types**
- `int`
- `double`
- `bool`

**Reference Types**
- `string`
- `int[]`
- `object`

### 2. Copy Behavior

Implemented examples demonstrating the difference between copying value types and reference types.

#### Value Type Copy
- Copied an integer value.
- Modified the copied variable.
- Verified that the original value remained unchanged.

#### Reference Type Copy
- Copied an integer array.
- Modified the copied array.
- Observed that both variables referenced the same object in memory.

### 3. Nullable Reference Types

Built a simple console application that:

- Reads a user's name using `Console.ReadLine()`.
- Validates the input with `string.IsNullOrWhiteSpace()`.
- Displays an error message if no valid name is entered.
- Greets the user when valid input is provided.

### 4. Git & GitHub

Performed basic version control operations:

- Installed Git.
- Configured Git username and email.
- Initialized a local repository.
- Added project files.
- Created commits.
- Connected the project to a GitHub repository.
- Pushed the project to GitHub.
