# Day 5 – Git & GitHub Workflow

## Overview

Day 5 focused on using Git and GitHub through a professional feature-branch workflow.

## Topics Covered

- Git fundamentals
- Feature branches
- Clear commit messages
- Pull Requests
- Merging changes into the main branch

## Hands-on Lab

- Confirmed that the local repository was connected to GitHub.
- Created a feature branch for the Week 1 README update.
- Updated the Week 1 documentation.
- Added and committed the changes with a clear commit message.
- Pushed the feature branch to GitHub.
- Opened a Pull Request from the feature branch into `main`.
- Reviewed and merged the Pull Request.
- Deleted the feature branch after merging.

## Commands Used

```bash
git remote -v
git branch
git checkout -b feature/Week1-summary
git add
git commit
git push
```
