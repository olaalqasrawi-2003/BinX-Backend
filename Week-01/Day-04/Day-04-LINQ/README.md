# Day 4 - C# Fundamentals III: Collections & LINQ Basics

## Topics Covered
- Collections (List<T>)
- LINQ Queries
- Where()
- Select()
- Count()
- Async/Await
- Exception Handling

## Hands-on Lab
Built a simple user management application using C# Collections and LINQ.

### Features
- Created a `List<User>` containing multiple users.
- Displayed all users using `foreach`.
- Filtered admin users using `Where()`.
- Selected user names using `Select()`.
- Counted the total number of users using `Count()`.
- Created an asynchronous method using `async` and `await`.
- Simulated data loading using `Task.Delay()`.
- Handled invalid user input using `try/catch` and `FormatException`.
